Workshop: สร้าง Test ด้วย Claude Code

ทดลองสร้าง Playwright Automated Test โดยเริ่มจาก Flow ที่มนุษย์เข้าใจ แล้วอธิบายสิ่งที่ต้องการให้ Claude Code ช่วยเขียน Code ให้

Workshop Session
WORKSHOP • ทำพร้อมผู้สอน

▶จาก Flow ที่ทำด้วยมือ สู่ Automated Test

เราจะลองทำรายการจริงก่อน 1 รอบ แล้วใช้ภาษาที่เข้าใจง่ายอธิบาย Flow ให้ Claude Code ช่วยสร้าง Playwright Test จากนั้นตรวจสอบ Code และ Run Test บน Browser จริง

1

เตรียมไฟล์สำหรับให้ Claude Code เขียน Test

สร้างไฟล์ Test เปล่าในโฟลเดอร์ tests ก่อนเริ่มสั่ง AI

เปิด Visual Studio Code → Explorer ทางซ้าย จากนั้นเปิดโฟลเดอร์ tests และสร้างไฟล์ใหม่ชื่อ nmw-motor-vibe-code.spec.ts

ทำไปเพื่ออะไร: เพื่อกำหนดให้ชัดเจนว่า Claude Code ต้องเขียน Automated Test ลงในไฟล์ใด ขั้นตอนนี้ยังไม่ต้องเขียน Code เอง
2

เลือกไฟล์ที่จะให้ Claude Code เขียน Code

เปิด Claude Code ใน VS Code และให้ไฟล์ Test อยู่ใน Context ที่ AI จะใช้ทำงาน

เปิด Claude Code Extension ใน Visual Studio Code แล้วตรวจสอบว่าด้านล่างของหน้าต่าง Claude Code แสดงชื่อไฟล์ nmw-motor-vibe-code.spec.ts

คำว่า Context คืออะไร: ในขั้นตอนนี้หมายถึงไฟล์ที่เราเลือกให้ Claude Code ใช้เป็นข้อมูลประกอบในการทำงาน เพื่อให้ AI รู้ว่าเราต้องการให้เขียน Code ลงในไฟล์ใด
3

ทดลองทำรายการด้วยตัวเองก่อนเขียน Automated Test

ลอง Flow จริง 1 รอบ เพื่อให้รู้ว่า Test ต้องเริ่มตรงไหน ทำอะไรบ้าง และจบเมื่อใด

เปิด Google Chrome แล้วเข้า URL สำหรับ Workshop:

https://tqm-main-web-qa.tqm-app-beta.com/car-insurance?utm_source=test
ทำไม URL มี ?utm_source=test: Workshop นี้ใช้หน้า QA/Test ที่กำหนดค่านี้ไว้เพื่อข้ามขั้นตอน CAPTCHA ทำให้ Automated Test สามารถทำงานต่อเนื่องตาม Flow ที่ใช้สอนได้

3.1 เลือกยี่ห้อรถ Toyota

ที่หน้าเช็กเบี้ยประกันรถยนต์ ให้เลือกยี่ห้อ Toyota แล้วไปขั้นตอนกรอกรายละเอียดรถ

3.2 กรอกข้อมูลรถและข้อมูลส่วนตัว

เลือก Toyota → Vios → ปี 2020 → รุ่นย่อยราคา 789,000 บาท → จังหวัดชลบุรี → คุ้มครองปีนี้ จากนั้นกรอกข้อมูลส่วนตัวตามตัวอย่าง และคลิก ดูแผนประกันเลย

3.3 ให้ความยินยอม

หากระบบแสดงหน้าต่าง เอกสารขอความยินยอม ให้ตรวจสอบข้อความแล้วคลิก ยินยอม เพื่อทำรายการต่อ

3.4 ตรวจสอบจุดสิ้นสุดของ Test

เมื่อ Browser แสดงหน้า /car-insurance/search ซึ่งเป็นหน้ารายการแผนประกัน ให้ถือว่า Flow ตัวอย่างนี้เดินทางมาถึงจุดสิ้นสุดที่เราต้องการทดสอบแล้ว

จุดสิ้นสุดของ Test: https://tqm-main-web-qa.tqm-app-beta.com/car-insurance/search
4

สั่ง Claude Code ด้วยภาษาที่เข้าใจง่าย

บอกสิ่งที่ต้องการทดสอบเป็นลำดับ โดยยังไม่จำเป็นต้องรู้ Locator หรือ data-testid

กลับไปที่ Visual Studio Code → Claude Code แล้วส่งคำสั่งด้านล่างให้ AI ช่วยสร้าง Automated Test

แนวคิดสำคัญ: ในขั้นตอนนี้เราอธิบายว่า “ต้องการทดสอบอะไร” และ “Flow ทำงานอย่างไร” ก่อน โดยไม่จำเป็นต้องรู้ล่วงหน้าว่า Element บนหน้าเว็บมีชื่ออะไร, Locator คืออะไร หรือ data-testid มีค่าอะไร
เขียน Code สำหรับทำ Automated Test ด้วย Playwright

5

ให้ Claude Code เริ่มวิเคราะห์และสร้าง Test

ส่งคำสั่งแล้วปล่อยให้ AI สำรวจ Project และหน้าเว็บตาม Flow ที่เราอธิบาย

หลังส่งคำสั่ง ให้ดูการทำงานในหน้าต่าง Claude Code โดย AI จะเริ่มอ่าน Project, เปิดหน้าเว็บ QA, ตรวจหา Element ที่ต้องใช้ และทดลองสร้าง Test ตาม Flow ที่เราให้ไว้

ตอนนี้เราไม่ต้องเขียน Locator เอง: เราไม่ได้บอก AI ว่า Toyota ใช้ data-testid อะไร หรือปุ่มต่าง ๆ ต้องใช้ Locator แบบไหน Claude Code จะเป็นผู้สำรวจและค้นหาข้อมูลเหล่านี้จากหน้าเว็บเอง
สิ่งที่ควรรู้ก่อนดูขั้นตอนถัดไป: AI อาจลองหลายวิธี พบ Error แล้วแก้ใหม่ได้ ลำดับข้อความที่เห็นจึงอาจไม่เหมือนภาพตัวอย่างทุกครั้ง สิ่งสำคัญคือสุดท้าย Test ต้องทำงานตรงตาม Flow ที่เรากำหนด
6

ดูการทำงานของ Claude Code ทีละขั้น

อธิบายภาพ 6.1–6.9 ว่า AI กำลังทำอะไร ตั้งแต่สำรวจ Project จน Run Test ผ่าน

ส่วนนี้ไม่ใช่ขั้นตอนที่ผู้เรียนต้องทำตามทีละคำสั่ง แต่เป็นการ อ่านสิ่งที่ Claude Code กำลังทำเบื้องหลัง เพื่อให้เข้าใจว่า AI ไม่ได้สร้าง Test ขึ้นมาทันที แต่ต้องสำรวจหน้าเว็บ ทดลอง และปรับ Code ก่อน

7

ตรวจสอบ Playwright Test ที่ Claude Code สร้างให้

เปิดไฟล์ Test และตรวจสอบว่า Code ถูกเขียนลงในไฟล์ที่เตรียมไว้

เปิด Visual Studio Code → Explorer → tests → nmw-motor-vibe-code.spec.ts แล้วตรวจสอบ Code ที่ Claude Code สร้างให้

สิ่งที่ควรสังเกต: Code ควรมีลำดับการทำงานใกล้เคียงกับ Flow ที่เราทดลองด้วยตัวเอง เช่น เปิด URL, เลือกรถ, กรอกข้อมูล, กดยินยอม และตรวจสอบว่าไปถึงหน้า /car-insurance/search
8

ตั้งค่าให้ Playwright เปิด Browser ระหว่าง Run Test

เปิด Show browser เพื่อให้เห็นขั้นตอนที่ Automated Test กำลังทำงาน

ใน Visual Studio Code คลิกเมนู Testing ทางซ้าย จากนั้นเลื่อนลงไปที่ Playwright → PROJECTS ให้เลือก chromium และที่ SETTINGS ให้ติ๊ก Show browser

ทำไปเพื่ออะไร: เพื่อให้ Browser แสดงขึ้นมาระหว่าง Run Test ทำให้ผู้เรียนเห็นว่า Playwright กำลังคลิก เลือก และกรอกข้อมูลบนหน้าเว็บอย่างไร
9

Run Automated Test จากเมนู Testing

สั่งรันไฟล์ Test ที่ Claude Code สร้างผ่าน Playwright Extension

ที่ Visual Studio Code → Testing → Test Explorer หา Test จากไฟล์ nmw-motor-vibe-code.spec.ts แล้วคลิกปุ่ม ▶ Run Test ที่อยู่ด้านขวาของชื่อ Test

10

ดู Playwright ทำงานบน Browser

ตรวจสอบว่า Automated Test ทำงานตาม Flow และไปถึงหน้าผลการค้นหา

เมื่อเริ่ม Run Test Browser จะเปิดขึ้นมา และ Playwright จะทำตาม Code ที่สร้างไว้โดยอัตโนมัติ เช่น เลือกรถ กรอกข้อมูล กดปุ่ม และดำเนินรายการต่อไปตาม Flow

Workshop สำเร็จ: เมื่อ Test ทำงานจนไปถึงหน้า /car-insurance/search และ Test แสดงสถานะผ่าน แสดงว่าเราได้สร้างและ Run Automated Test ด้วย Claude Code สำเร็จแล้ว

สิ่งที่ได้เรียนรู้จาก Workshop นี้

เราไม่จำเป็นต้องเริ่มจากการจำ Locator หรือ data-testid ทุกตัว เริ่มจากทดลอง Flow ให้เข้าใจก่อน แล้วอธิบายสิ่งที่ต้องการทดสอบด้วยภาษาที่เข้าใจง่าย ให้ Claude Code ช่วยสร้าง Code จากนั้นมนุษย์เป็นผู้ตรวจสอบและ Run Test จริง เพื่อยืนยันว่า Automated Test ทำงานตรงกับสิ่งที่ต้องการ
