ติดตั้ง Playwright

ติดตั้ง VS Code Extension และสร้าง Playwright Test Project สำหรับเริ่มเขียน Automated Test

1

ติดตั้ง Playwright Test for VSCode

ติดตั้ง Extension ของ Microsoft เพื่อช่วย Run และ Debug Test จาก VS Code

1. คลิกไอคอน Extensions ที่แถบด้านซ้ายของ VS Code

2. ที่ช่องค้นหา พิมพ์ playwright

3. เลือก Playwright Test for VSCode ที่พัฒนาโดย Microsoft แล้วคลิก Install

Extension คืออะไร? เป็นส่วนเสริมของ VS Code ที่ช่วยให้เห็น Test Explorer และสามารถ Run / Debug Test ได้สะดวกขึ้น แต่ยังไม่ใช่การติดตั้ง Playwright ลงใน Project ตัว Playwright หลักจะติดตั้งด้วย npm ในขั้นตอนถัดไป

npm init playwright@latest

ครั้งแรก npm อาจถาม Ok to proceed? (y) ให้พิมพ์ y แล้วกด Enter เพื่ออนุญาตให้ดาวน์โหลดตัวสร้าง Project

3

กำหนดค่าตอนสร้าง Project

แต่ละคำถามกำหนดโครงสร้างและความสามารถเริ่มต้นของ Project
TypeScript หรือ JavaScript → TypeScript
เลือกภาษาที่ใช้เขียน Test โดย TypeScript ช่วยตรวจชนิดข้อมูลและช่วยลดข้อผิดพลาดตอนเขียนโค้ด เหมาะสำหรับใช้เป็นมาตรฐานของ Project
Where to put your end-to-end tests? → tests
กำหนด Folder สำหรับเก็บ Test Case ใช้ค่า tests เพื่อให้ไฟล์ทดสอบรวมอยู่ในตำแหน่งเดียวและหาได้ง่าย
Add a GitHub Actions workflow? → false / No
GitHub Actions ใช้รัน Test อัตโนมัติบน GitHub เช่น เมื่อ Push หรือ Pull Request สำหรับการเรียนและรันในเครื่องครั้งนี้ยังไม่ใช้ จึงเลือก No
Install Playwright browsers? → true / Yes
ให้ Playwright ดาวน์โหลด Browser ที่ใช้ทดสอบ เช่น Chromium, Firefox และ WebKit หากไม่ติดตั้ง Browser จะยังรัน Browser Test ไม่ได้
ระหว่างติดตั้ง: ระบบจะสร้าง package.json, ติดตั้ง @playwright/test, สร้าง playwright.config.ts, สร้าง Example Test และดาวน์โหลด Browser ที่จำเป็น
ภาพนี้ยังอยู่ระหว่างติดตั้ง: ระบบกำลังติดตั้ง Package และดาวน์โหลด Browser เช่น Chromium, Firefox และ WebKit ให้รอจนกระบวนการทำงานเสร็จ ไม่ต้องปิด Terminal
กรณีพบ Timeout ระหว่างดาวน์โหลด: ในภาพนี้มีข้อความ timed out after 30000ms ตอนดาวน์โหลด Firefox หนึ่งครั้ง แต่ Playwright ดาวน์โหลดซ้ำและทำงานต่อได้
ติดตั้งสำเร็จ: ให้ตรวจสอบข้อความ Success! Created a Playwright Test project ที่ด้านล่างของ Terminal หากขึ้นข้อความนี้ แสดงว่าสร้าง Project สำเร็จแล้ว
4

ทำความรู้จักไฟล์ Example Test

เปิดไฟล์ tests/example.spec.ts ที่ Playwright สร้างให้หลังติดตั้ง

หลังสร้าง Project สำเร็จ จะมีตัวอย่าง Test อยู่ในโฟลเดอร์ tests ให้คลิกเปิดไฟล์ example.spec.ts เพื่อดูรูปแบบการเขียน Test เบื้องต้น

import { test, expect } from '@playwright/test';
นำเครื่องมือ test และ expect จาก Playwright มาใช้ โดย test ใช้สร้าง Test Case และ expect ใช้ตรวจสอบผลลัพธ์ว่าตรงตามที่เราคาดหวังหรือไม่
Test Case: has title
เปิดเว็บไซต์ https://playwright.dev/ แล้วตรวจสอบว่า Title ของหน้าเว็บมีคำว่า Playwright
Test Case: get started link
เปิดเว็บไซต์ Playwright → คลิกลิงก์ Get started → ตรวจสอบว่ามีหัวข้อ Installation แสดงอยู่บนหน้าเว็บ
ในภาพ: ได้เพิ่ม Comment ภาษาไทยไว้ในโค้ด เพื่อให้ผู้เริ่มต้นอ่านตามแต่ละบรรทัดและเข้าใจหน้าที่ของคำสั่งได้ง่ายขึ้น
5

Run Test ผ่าน Terminal

วิธีมาตรฐานสำหรับรัน Test ทั้งชุดจาก Command Line

รันคำสั่ง:

npx playwright test

คำสั่งนี้จะค้นหา Test ใน Project แล้วรันตาม Browser/Project ที่กำหนดไว้ใน playwright.config.ts จากตัวอย่างมี 2 Test Case และรันบน Chromium, Firefox และ WebKit จึงรวมเป็น 6 tests

6 passed หมายถึงการทดสอบทั้ง 6 รายการผ่านทั้งหมด
6

เปิด Playwright HTML Report

หลัง Run Test สามารถเปิด Report ด้วยคำสั่ง:

npx playwright show-report

Playwright จะเปิด Web Server ในเครื่องและแสดง Report ผ่าน Browser เช่น http://localhost:9323 สามารถดูว่า Test ไหน Passed / Failed และดูผลแยกตาม Browser ได้

หากต้องการหยุด Report Server ให้กลับมาที่ Terminal แล้วกด Ctrl + C
7

ตั้งค่า Playwright Report, Screenshot, Video และ Trace

กำหนดรูปแบบ Report และหลักฐานที่ต้องการเก็บหลังรัน Test

เปิดไฟล์ playwright.config.ts แล้วแทนค่าตั้งต้นด้วย Config ด้านล่าง เพื่อให้เปิด HTML Report อัตโนมัติ รัน Browser แบบมองเห็นหน้าจอ และเก็บ Screenshot, Video และ Trace ทุกครั้ง

import { defineConfig } from '@playwright/test';

export default defineConfig({
  reporter: [
    ['html', { open: 'always' }]
  ],

  use: {
    headless: false,
    browserName: 'chromium',

    screenshot: 'on',
    video: 'on',
    trace: 'on',
  },
});
ความหมายแบบสั้น ๆ
open: 'always' = เปิด HTML Report ทุกครั้งหลังรัน Test
screenshot: 'on' = เก็บ Screenshot ทุกครั้ง
video: 'on' = อัด Video ทุกครั้ง
trace: 'on' = เก็บ Trace ทุกครั้ง เพื่อนำมาเปิดดูย้อนหลังได้
ตัวเลือกอื่นที่ใช้ได้

Report
never = ไม่เปิด Report อัตโนมัติ
on-failure = เปิด Report เฉพาะเมื่อ Test Fail

Screenshot
only-on-failure = เก็บภาพเฉพาะเมื่อ Test Fail
off = ไม่เก็บ Screenshot

Video
retain-on-failure = เก็บ Video เฉพาะ Test ที่ Fail
on-first-retry = อัด Video ตอน Retry ครั้งแรก
off = ไม่อัด Video

Trace
retain-on-failure = เก็บ Trace เฉพาะ Test ที่ Fail
on-first-retry = เก็บ Trace ตอน Retry ครั้งแรก
off = ไม่เก็บ Trace

สามารถเลือกใช้ให้เหมาะกับการทำงานของแต่ละ Project ได้

รัน Test และเปิด Report อัตโนมัติ

ตัวอย่างนี้รันเฉพาะไฟล์ tests/example.spec.ts และใช้ --headed เพื่อให้เห็น Browser ขณะ Test ทำงาน

npx playwright test tests/example.spec.ts --headed
ภาพนี้คือผลหลังรัน Test สำเร็จ
ข้อความ 2 passed หมายถึง Test ผ่านทั้งหมด 2 Test Case และเนื่องจากตั้งค่า Report เป็น open: 'always' ระบบจึงเริ่มเปิด HTML Report อัตโนมัติที่ http://localhost:9323

คลิกเข้าไปที่ Test Case จะเห็นรายละเอียดขั้นตอน รวมถึง Screenshot, Trace และ Video ที่เก็บไว้จากการรันครั้งนั้น

ดาวน์โหลด Trace มาเปิดดูในเครื่อง

ในหน้า Report คลิก trace เพื่อดาวน์โหลดไฟล์ Trace จากนั้นแตกไฟล์ออกเป็นโฟลเดอร์ เพื่อใช้เปิดดูรายละเอียดย้อนหลัง เช่น Action, Timeline, Network และภาพในแต่ละช่วงของ Test

หากต้องการดูตำแหน่งโฟลเดอร์ ให้คลิกขวาที่โฟลเดอร์ trace → Properties แล้วคัดลอก Path

จากนั้นใช้คำสั่ง npx playwright show-trace ตามด้วย Path ของโฟลเดอร์ Trace

npx playwright show-trace C:\Users\sittikorn.mue\Downloads\trace
ภาพนี้คือ Playwright Trace Viewer
ใช้สำหรับเปิดดูเหตุการณ์ที่เกิดขึ้นระหว่างการรัน Test แบบย้อนหลัง สามารถเลือกแต่ละ Action จาก Timeline เพื่อดูว่า Playwright ทำอะไร ณ ช่วงเวลานั้น พร้อมตรวจสอบภาพหน้าเว็บ, เวลาในการทำงาน, Network และข้อมูลประกอบอื่น ๆ ช่วยให้หาสาเหตุของ Test Fail ได้ง่ายขึ้น
8

Run Test ผ่าน Playwright Test for VSCode Extension

รัน Test โดยกดปุ่ม ▶ ใน VS Code โดยไม่ต้องพิมพ์คำสั่งใน Terminal

วิธีนี้ใช้ Playwright Test for VSCode Extension ที่ติดตั้งไว้ก่อนหน้านี้ Extension จะเพิ่มเมนู Testing และ Test Explorer เข้ามาใน VS Code เพื่อให้รัน Test ได้จากหน้าจอโดยตรง

วิธีรัน: คลิกไอคอนรูป ขวดทดลอง (Testing) ทางซ้ายของ VS Code → เลือก Test Case ที่ต้องการ → กด ▶ Play แล้วรอดูผล Passed หรือ Failed ภายใน VS Code

หลังรันเสร็จ VS Code จะแสดงผลบริเวณ Test Explorer และ Test Results หากผ่านจะเห็นเครื่องหมาย ✓ สีเขียว รวมถึงจำนวน Test ที่ผ่าน เช่น 1 passed

1 passed หมายถึง Test Case ที่เลือกผ่านสำเร็จ 1 รายการ

ต่างจากการรันผ่าน Terminal อย่างไร?

หัวข้อรันด้วยคำสั่งใน Terminalรันด้วย Playwright Extension
วิธีรันพิมพ์ npx playwright testคลิก ▶ Play จาก Test Explorer
เหมาะกับรันหลาย Test, รันทั้งชุด, ใช้ใน Script หรือ CI/CDรันทีละ Test ระหว่างพัฒนา หรือทดสอบจุดที่กำลังแก้
การเลือก Testเลือก Test ผ่านคำสั่งและตัวเลือกที่พิมพ์ต่อท้ายคำสั่งเห็นรายชื่อ Test แล้วคลิกเลือกได้ทันที
การดูผลดูข้อความ Passed / Failed ใน Terminal และเปิด Report เพิ่มได้ดูสถานะ ✓ / ✕ และ Test Results ภายใน VS Code ได้ทันที
